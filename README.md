# LG TRADES

LG TRADES is a **Consumer-to-Consumer (C2C) e-commerce marketplace** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The platform enables users to securely buy and sell gaming and technology products through a user-friendly web interface.

The system allows every registered user to act as both a buyer and a seller. Users can create accounts, list products, manage their inventory, purchase items, track orders, and monitor sales from dedicated dashboards. To enhance transaction security, LG TRADES includes a wallet system with **PayFast** integration, allowing users to deposit funds securely before making purchases.

## Features

* User registration and secure authentication
* Buyer and seller dashboards
* Product listing, editing, and deletion
* Digital product catalogue with search functionality
* Wallet system with PayFast deposit integration
* Secure purchasing and checkout process
* Order and sales tracking
* Inventory management
* Administrator dashboard for managing users, products, orders, and deposits
* Session management and server-side input validation for improved security

## Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Payment Gateway:** PayFast
* **Server Environment:** Apache (XAMPP)

## Purpose

This project was developed as part of a Software Engineering practical project to demonstrate the design and implementation of a secure, full-stack C2C e-commerce platform. It showcases core web development principles, database design, payment integration, user authentication, and e-commerce functionality while following industry best practices for security and usability.
